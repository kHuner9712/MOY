#
# 为什么需要单独一份：G-37 的 12×12 层矩阵只判**跨层方向**。
#   · 同层文件之间互相 import（business ↔ business、workers ↔ workers）在矩阵里
#     属于「同层自引用恒允许」，**完全不进判定**；
#   · `core ↔ business` 这类跨层环会被拆成两条记录（一条合法、一条已登记），
#     从基线上看不出它们其实闭成了环 —— 运行期就是延迟初始化顺序的定时炸弹。
# 因此每轮扫描额外跑一遍文件级 import 图的 Tarjan 强连通分量（成员数 >= 2 即一个环）。
#
# 格式：
#   CYCLE <file> <file> [<file>...] -- <审计编号> due_batch=<Bn> <消除计划>
#   · 成员顺序不敏感（加载时按路径排序后精确匹配），成员增减即视为「不同的环」；
#   · 只许减不许增：新增环 = [FAIL] exit 1；环消失但没删行 = [FAIL] stale exit 1；
#   · due_batch 与 import_direction_baseline.txt 同源（OA_BATCH 时钟），到期即红。
#
