# ADR-0008：品牌化、前端测试与连接器阻塞的决策

| 项 | 内容 |
| --- | --- |
| 记录版本 | v1.0 |
| 决策日期 | 2026-10-25 |
| 决策人 | 用户（桐鸣科技创始人） |
| 记录人 | 齐活林（交付总监） |
| 适用范围 | V1.0 阶段四及后续批次 |

## 1. 背景

Batch 1 收口后，有三项待确认事项会直接影响后续排期：品牌命名、前端测试依赖、首批连接器真实账号。用户在 2026-10-25 给出明确裁定。

## 2. 决策

| # | 事项 | 决策 | 影响 |
| --- | --- | --- | --- |
| D-44 | 品牌 | **必须品牌化**，V1.0 对外统一使用「麦子 / Moy」，不再保留白标「办公 AI 平台」作为并行选项 | 侧栏、登录页、页面 metadata、favicon 全部切换；`BRAND` 常量成为唯一文案来源 |
| D-45 | 前端测试 | **允许新增 vitest + @playwright/test** | 单元测试覆盖纯函数与表单合并规则；E2E 覆盖登录页品牌与降级；CI 增加 vitest 步骤 |
| D-46 | 连接器 | 用户**暂时无法提供** 5 款连接器的名单与真实账号 | 连接器真实化（A-03）继续阻塞；不得以桩实现对外声明 L3；Batch 3 先做本地 sink / 契约测试，真实联调待账号到位 |

## 3. 品牌实现口径

- 中文名：麦子；英文名：Moy；主张：Mate Of You / 与你一起把工作做好。
- 唯一来源：`apps/web/src/lib/brand.ts`；组件：`components/brand/brand-mark.tsx`。
- 麦穗方块用于识别，不承担解释；不在每个导航项重复品牌名。
- 技术黑盒化不变：界面仍不出现模型名、向量库、RAG、Agent、错误码与堆栈。

## 4. 前端测试口径

- `npm run test --workspace apps/web`：vitest，纯函数优先（登录回跳、会话广播、表单默认值合并与校验）。
- `npm run test:e2e --workspace apps/web`：Playwright，使用本机 Chrome（`channel: 'chrome'`），不下载 Chromium；覆盖登录页品牌与统一登录降级。
- CI 只跑 vitest；E2E 需要浏览器与运行环境，暂不进 CI。
- monorepo 根目录存在 React 18（工具链），`apps/web` 为 React 19；单测避免引入 React 渲染器，防止两套 React 混用。该约束写入 `vitest.config.mts` 注释。

## 5. 连接器阻塞的处置

1. 不把 5 个桩连接器计入「深度打通」；PRD 成熟度保持 L1。
2. Batch 3 可先做：邮箱 SMTP 本地 sink（可达 L3 的真实会话）、GitHub 受控测试账号方案、出站白名单设计。
3. 真实账号到位前，任何对外材料不得写「已打通企业微信/飞书/公众号/邮箱/GitHub」。
4. 需要用户后续提供：各平台测试账号或 OAuth 应用、发件邮箱 SMTP 凭据、出站白名单审批。

## 6. 后果

- 正面：品牌不再分裂；前端缺陷有回归防线；连接器状态诚实。
- 负面：E2E 暂不进 CI，需本地执行；连接器差异化能力在账号到位前无法闭合，Gate 4 的 §6.1 仍不通过。
