## 一、豁免清单

### W-01 ｜ G-05 测试覆盖率（总覆盖率）

| 字段 | 内容 |
| --- | --- |
| 门禁编号 | G-05（总覆盖率） |
| 阈值 | ≥ 90.5% |
| 当前实测 | **88.06%**（HEAD `f168e85`，`pytest --run-pg --cov=app`） |
| 申请批次 | B05 起 |
| 豁免理由 | ① 总方案 §5.1 的强制要求是「核心接口覆盖率不低于 80%」，90.5% 是阶段一遗留的内部高标准，当时代码面窄（421 用例、单层服务）；② 阶段二新增 25 张表、38 个端点、5 个业务服务，分母从 3.9k 行涨到 6.1k 行，短时间内抬到 90.5% 需大量无业务价值的 getter 覆盖；③ 覆盖率自 B03 起持续改善（85.05% → 85.97% → 87.10% → 88.06%），非质量退化。 |
| 约束（硬性） | ① **总覆盖率硬地板 85%**（高于总方案 5.1 的 80%），低于 85% 立即红；② 每批次允许波动 ≤0.5pp，且不得连续两批下降；③ **B15 收尾前必须 ≥90.5%**，未达则阶段二不放行。 |
| 补偿措施 | ① 每个批次必须为新代码补测试，覆盖率不达标不得提交；② `scripts/reconcile_usage.py`、`check_error_catalog.py` 等运维脚本纳入单测；③ B15 专项补测（前端三态与后端错误分支）冲抵缺口。 |
| 到期批次 | **B07 复核**（复核是否仍 ≥85%）、**B15 关闭**（必须 ≥90.5%） |
| 签字 | 齐活林 · 2026-10-22 |
